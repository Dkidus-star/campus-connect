# 🎓 CampusConnect

**🌍 Live Demo:** [View the live application here]([https://campus-connect-sigma-ashen.vercel.app/])

CampusConnect is a modern, responsive web application designed to centralize university life. It provides students with a beautifully curated digital lens to discover campus clubs, track upcoming events, and access vital academic resources.

The project features a premium, high-contrast design system inspired by top-tier creative agencies, utilizing glassmorphism, massive typography, and fluid, physics-based animations.

## ✨ Key Features

- **Dynamic Client-Side Routing:** Seamless, lightning-fast navigation without page reloads utilizing React Router.
- **Global State Management:** Users can favorite clubs and persist their selections across the application utilizing the React Context API.
- **Simulated Asynchronous Data:** Implements realistic data fetching flows, complete with loading states and error handling via `useEffect`.
- **Real-time Search Filtering:** Instantly filter available clubs by name via controlled component state.
- **Premium UI/UX:** Fully responsive layout built with Tailwind CSS, featuring staggered entrance animations and smooth hover states powered by Framer Motion.
- **Custom 404 Handling:** Graceful error routing for invalid URLs.

## 🛠 Tech Stack

- **Framework:** React 18 (via Vite)
- **Styling:** Tailwind CSS
- **Routing:** React Router v6
- **Animation:** Framer Motion
- **State Management:** React Hooks (`useState`, `useEffect`, `useContext`)
